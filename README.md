# Alaba Commerce UI

A modern React + TypeScript frontend with Spring Boot + Java integration for the Alaba Commerce e-commerce platform.

---

## Overview

Alaba Commerce allows buyers to browse products and sellers to manage inventory through a secure dashboard.

The frontend communicates with a Spring Boot REST API.

---

## Features

### Authentication

- JWT Login
- Registration
- Protected Routes
- Buyer & Seller Roles

### Buyers

- Browse products
- Product Details
- Category Filtering
- Search Products
- Shopping Cart
- Pagination
- Sorting

### Sellers

- Seller Dashboard
- Create Product
- Edit Product
- Delete Product
- Upload Product Images
- Manage Inventory
